    Un defecto real, de principio a fin

    El botón de conversión dejó de responder

    dragonflaievents.com · producto propio en producción
    resuelto
    Síntoma reportado

    El botón principal de conversión — "Generar mi plan personalizado" — dejaba de responder sin mostrar ningún error visible al usuario. El peor tipo de falla desde QA: silenciosa.

    Diagnóstico
    • Reproducción controlada en producción con DevTools (consola + Network), para descartar backend primero.
    • Confirmé que no se disparaba ninguna llamada a la API antes de la falla — acotó el problema a lógica del cliente.
    • Stack trace exacto capturado: TypeError: Cannot read properties of undefined (reading '0').
    Stack trace
    TypeError: Cannot read properties of undefined (reading '0') at generate (app:4234:97) at HTMLButtonElement.onclick (app:1082:65)
    Causa raíz

    Un objeto de datos indexado primero por tipo de evento y luego por idioma se leía en una línea como si estuviera indexado directamente por idioma — inconsistente con el patrón correcto ya usado en otra parte del propio código.

    Fix aplicado
    - T.priority[lang][0]
    + (T.priority[eventType] || T.priority['Boda/Wedding'])[lang][0]
    Verificación

    Sintaxis del archivo completo verificada antes de entregar, para no introducir una regresión nueva al corregir la original. Documentado con el mismo formato que usaría en un entorno corporativo con control de cambios: síntoma → reproducción → causa raíz → fix → verificación.
